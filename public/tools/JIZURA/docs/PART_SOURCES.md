# 已有与后加部件

这里的分组仅用于控制素材库显示，不再追溯 fork 来源，也不表示原创归属。

- **后加**：用户确认的 CL 装饰，以及 2026-11-03 固定清单之后新增的部件 ID。
- **已有**：沿用之前已隔离的部件清单。并不声称这些部件全部来自上游。
- **保留**：此前仍显示的其他部件，保持显示，不再未经核实地称为后加或原创。
- **基础**：清空、瞬切、静止、标题/间奏卡等功能项。字体、配色与当前全片样式继续可用。

顶部「一键隐藏原有部件」仍控制浏览、搜索、风格模板和自动抽选；只隐藏「已有」清单，保留 CL 和其他原先保留的内容。开关随项目保存，支持撤销及一键恢复。已有手动指定和锁定镜头不改动。

`src/11s_part_baseline.js` 是固定部件 ID 清单。**以后新增部件时不要重新生成或扩充这个清单。** 新 ID 无论放在新文件、已有文件、已有包，还是使用默认注册包，都会自动判为后加；不是靠文件名或包名判断。注册在筛选模块之前和之后均适用。修改同一个旧 ID 仍视为已有部件；若要作为新部件使用，应注册一个新 ID。

`src/11s_part_sources.js` 处理分组和筛选。旧字段 `source: upstream/modified/unknown` 仅兼容映射到「已有/保留/保留」，界面不再显示原版或原创判断。只需维护实用的隔离清单，没有必要再做来源鉴定。

自动候选为空时不重新开放已有池；布局可回退为居中文字，运镜可回退为静止。隐藏不删除部件，不改变手法启用列表，也不调整全局动效滑块。

验证：`node --test dev/part_sources_test.cjs dev/vibe_test.cjs dev/shot_editor_test.cjs dev/screen_fx_editor_test.cjs dev/project_compat_test.cjs`；构建：`python build.py`。
