# 镜头调节区

镜头模式仅保留左栏与预览：时间轴和缩放工具栏隐藏；原右栏风格、手法及导出设置合并到左栏「全片设置与导出」。动效模式继续使用独立动效时间轴与事件参数面板。

歌词输入与镜头列表集中在左栏。点击歌词行、镜头按钮或时间轴上的镜头，即进入底部横跨工作区的镜头调节区；歌词输入自动收起，仍可从左栏「编辑歌词」展开。

调节区左侧为定宽、定高的竖排分类（布局、字体、配色、入场、保持、退场、装饰等），右侧展示相应选项预览。类别名称不会随所选效果改变长度。上／下方向键切换分类，Home／End 跳到首尾。

编辑目标固定为选中的镜头；播放经过其他镜头不会切换目标。切换镜头保留当前分类并清空搜索。顶部可复制、粘贴、同步或收起；切到画面动效模式会关闭镜头调节区。自动生成的标题卡仍可选择并使用删除等卡片操作。

验证：`node --test dev/shot_editor_test.cjs dev/screen_fx_test.cjs dev/screen_fx_editor_test.cjs dev/gap_test.cjs dev/palette_test.cjs`。

## 部件风格、星宿叹与坍缩星

每个镜头参数类别下增加风格选项卡：全部、通用、星宿叹、坍缩星，以及由现有标签生成的故障、静谧、流行、图形、编辑排版、情绪、惊悚。切换参数类别或镜头会保留当前风格；浏览与搜索不会改变自动生成范围。

星宿叹与坍缩星为平级的定制收录标签，初始为空，不预设歌曲的视觉方向。点击「管理星宿叹收录」或「管理坍缩星收录」，选择「收录为通用搭配」「收录为专属」或「移出收录」，再点击部件卡片。管理模式下不替换镜头；完成后点击「完成收录」。通用搭配保留在通用分类，专属部件只从本项目的通用分类中隐藏。各收录标签内可进一步筛选全部收录、专属部件、通用搭配。收录关系随项目保存、导入导出，并支持撤销／重做。

「自动生成范围」单独控制生成候选，可选择一个风格，并选择是否同时允许通用部件。尚无收录的类别继续使用原有候选；原有追加分、和风、手法开关继续生效。若没有适配歌词长度的布局，生成器保留原有基础布局回退。手动指定与已锁定的镜头优先。字体跟随收录筛选，配色按原样式及原索引引用，不重新编号；切换全片样式后不会把另一个样式的同号配色误当成已收录配色。

实现位于 `src/11r_vibes.js`；星宿叹与坍缩星专属部件分别收录于 `src/11p_xxt.js` 和 `src/11p_collapsar.js`。新风格可加入 `J.VIBES`。新部件可以用 `vibes: ['xxt']` 或 `vibes: ['collapsar']` 标注归属，用 `vibeExclusive: true` 标注专属；同一部件可以引用多个风格，无需复制注册。

风格验证：`node --test dev/vibe_test.cjs`。

## 装饰多选叠加（方案 A）

在镜头调节区中，分类切换至「装饰」时支持**多选开关（Toggle）模式**：
- **点击切换**：未选中的卡片点击激活并加入该镜头的装饰层列表；已选中的卡片再次点击则取消。卡片上清晰标注了 `[前景]` 或 `[后景]` 层级标识。
- **清空与自动**：点击「无 (なし)」可一键清空该镜头全部装饰；点击「自动」重置为规划器自动抽选。
- **底层与分层渲染**：底层技术参数 `cutTech[k].decor` 存储为数组（向后兼容单字符串与逗号分隔），规划器同时生成各装饰部件参数，渲染器（`09_render.js`）按前景与后景层级同时叠加渲染。
- **复制与同步**：支持镜头间参数复制／粘贴及一键同步整行或全片。
- 多装饰测试验证：`node --test dev/multi_decor_test.cjs`。
