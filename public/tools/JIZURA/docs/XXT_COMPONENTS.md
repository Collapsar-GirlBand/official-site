# 星宿叹：清冷星图与古典宿命

`src/11p_xxt2.js` 新增 12 个原创部件，全部使用 `vibes: ['xxt']` 与 `vibeExclusive: true`，无需手动收录即可在「星宿叹 → 专属部件」找到。保留已有 `src/11p_xxt.js` 的部件。

| 类别 | 名称 | 表现 |
|---|---|---|
| 布局 | 星官连字 | 字下星点以细线连缀，长歌词折为多层星图 |
| 布局 | 宿命书简 | 淡纸笺与两侧细栏，衬线字配宽松行距 |
| 布局 | 隔岸双星 | 两段歌词遥相对望，中央连线留出断口 |
| 装饰 | 垂星签 | 页边悬挂的星点与宿命小签 |
| 装饰 | 未续红线 | 画面边缘一端实心、一端空心的断线；颜色跟随强调色 |
| 装饰 | 月相页边 | 页边五枚月相图形，横竖屏自动调整方向 |
| 背景 | 寂夜星历 | 低对比星点、弧形坐标与缓慢明暗变化 |
| 入场 | 寒露凝字 | 字符逐一微升显现，准确归位 |
| 保持 | 恒星微息 | 极轻的缓慢起伏与明暗呼吸，跟随运动强度 |
| 退场 | 叹息留白 | 从末字向前逐渐消隐，轻微上浮与散开 |
| 运镜 | 长夜守望 | 轻微横移与缓慢推进，保留歌词安全区 |
| 转场 | 月蚀过笺 | 弧形月缘缓慢扫过，露出下一镜头 |

建议先用「宿命书简＋垂星签＋寂夜星历」，句尾搭配「叹息留白」。需要加强歌词之间的关系时，使用「隔岸双星＋未续红线」。这些部件跟随当前配色；蓝黑、冷白、低饱和金的组合适合这套方向。坐标与月相为示意图形，不是实测天文数据。

切换到「星宿叹」只筛选浏览。需要自动生成使用该包时，另选「自动生成范围：星宿叹」。新部件不进入「通用」分类；全风格浏览仍可看到它们。AE 导出使用所声明的基础部件近似替代，未添加专门的 AE 原生实现。

验证：

```powershell
node --test dev/xxt2_test.cjs dev/vibe_test.cjs
# NODE_PATH 指向包含 @napi-rs/canvas 的库目录：
node dev/xxt2_preview.cjs
python build.py
```

原生 Canvas 预览默认输出到 `build/xxt2-preview/`，包括横竖屏预览和总览图，并检查短句、长句及拉丁歌词的静止文字边界。
