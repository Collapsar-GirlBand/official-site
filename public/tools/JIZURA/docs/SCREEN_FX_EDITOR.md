# 画面动效编辑

点击预览上方的「画面动效」进入工作区。

- 左侧效果库支持分类、搜索、悬停／键盘聚焦动态预览。点击添加到播放头，或拖到时间轴。
- 下方动效轨显示自动与手动事件。点击选择、拖动移动、拖右边缘调整时长；重叠事件分行显示。
- 右侧参数只作用于选中事件，可调类型、起点、强度、时长，支持禁用、复制、删除。自动事件可恢复原始生成值。
- 方括号左右键按帧微移，Shift 加方括号移动 10 帧；Delete 删除。吸附拍点可关闭，拖动时 Shift 临时取消吸附。
- 「循环预览所选」反复播放事件前后的小段；暂停、选择其他事件或拖动播放位置会退出循环。
- 默认单画面。「并排对比」比较最终画面与不含时间点事件的原画面；「旁路动效」仅影响预览。
- 「全片风格与自动生成」中保留生成模式、全片转手动、清空与全局参数。选择自动事件不改项目，修改仅创建该事件的覆盖。
- 项目保存包含局部覆盖、禁用与删除记录；撤销／重做可恢复编辑。旧项目无需迁移。

自动事件身份跟随所属镜头、类型及出现序号；大幅重排镜头或改变随机种子可能产生新的事件身份。范围生成、收藏和曲线编辑不在本次实现范围内。

验证：`node --test dev/screen_fx_test.cjs dev/screen_fx_editor_test.cjs dev/gap_test.cjs dev/palette_test.cjs`。生成页面：`python build.py`。
