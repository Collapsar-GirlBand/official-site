本工具是我基于开源项目 JIZURA 自行魔改的版本，用于在浏览器中制作歌词动态视频。

基于原版进行中文界面、操作体验与功能调整，属于个人修改版本。

使用方法

  1. 导入歌曲，填写曲名与歌手，输入歌词或导入带时间轴的 LRC 歌词。
  2. 检查每行歌词的时间，点击“一键随机”生成效果，再按需要调整片段、风格、字体和配色。
  3. 预览确认后，在导出面板选择画面比例、分辨率等参数，导出 MP4 或 PNG 序列。
  4. 使用“保存”下载项目 JSON，以便下次继续编辑；建议同时保留原始音频文件。

顶部“日间 / 黑夜”按钮切换编辑界面配色，选择会保存在当前浏览器中；首次打开跟随系统。界面配色不会改变视频效果或导出内容。
