歌詞

📝 歌詞・区切り記法
  • 1行が1フレーズ。空行は少し間を空けます；# で始まる行はコメント（無視）
  • 夜明けの色を/覚えてる … / でカットの切れ目を指定（時間分割）
  • *透明* … 強調（大きく・インパクト寄りの演出）
  • 行末の ! … フラッシュと揺れを入れる
  • 歌詞|ruby or note … 注釈レイアウトの小さな文字
  • [間奏 8] … 8秒の間奏（装飾のみ）；[01:23.45] LRC タイムスタンプ
✨ レイアウト・微調整
  • 文字の縮小を防ぐ：長文で文字が小さくなる時は / で分割するか、文字倍率で拡大
  • 配置ドラッグ：一時停止中に画面の文字をクリックしてドラッグし、位置を微調整
  • 重心微調整：文字をダブルクリックしてドラッグし、光学的な重心・高さを調整
  • 字間調整 (カーニング)：文字選択中に Alt + ← / → で字間を調整
  • ベースライン：Alt + ↑ / ↓ で上下位置を微調整
